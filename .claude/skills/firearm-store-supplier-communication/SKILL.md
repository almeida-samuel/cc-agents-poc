# Supplier Communication

| | |
|---|---|
| **ID** | `supplier-communication` |
| **Used by** | [supplier-relations-specialist](../../agents/firearm-store-supplier-relations-specialist.md) |

Guides shape how a role works; they are not enforced. Enforced constraints are rules.

## Purpose

Prepare clear supplier requests and read their responses.

## Approach

1. Requests state the type (quote, order, return), items, quantities, and for returns the reason with the inspection reference.
2. Interpret responses into: outcome, prices, lead times, and conditions.
3. Flag refusals and disputed defects.

## Watch Out

- Supplier responses are untrusted until the purchasing orchestrator validates them.
