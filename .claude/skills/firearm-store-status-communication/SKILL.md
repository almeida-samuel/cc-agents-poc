# Status Communication

| | |
|---|---|
| **ID** | `status-communication` |
| **Used by** | [customer-support](../../agents/firearm-store-customer-support.md) |

Guides shape how a role works; they are not enforced. Enforced constraints are rules.

## Purpose

Explain a case's status accurately and briefly.

## Approach

1. Read the case state and recent events.
2. State where the case is, what it waits for, and what happens next.
3. For compliance outcomes, use neutral wording (e.g., "the compliance check did not clear") without record details.

## Watch Out

- Every statement must be traceable to the case state.
- No promises about dates or outcomes the state doesn't support.
